Product direction · final revision · floating-notes model

Stickies, but blazing fast.

One shortcut — ⌘⇧. — shows or hides all your floating notes at once, snapping them back over whatever you're doing with focus on the one you used last. Borderless, always-on-top, unlimited. Every note is its own little window; open several and they scatter across the desktop like modern stickies — all on rich Markdown files you own. Toggle the theme top-right; each mockup is fixed to its intended look.

01The hero surface

Summon your notes (⌘⇧.)

⌘⇧. shows or hides every floating note at once — they land over whatever you're doing, focus on the last one used. The note header reads icon, then title and description, with its group and tags just beneath. The focused window is marked only by a quiet gold edge — no chrome, no clutter.

03Find & open ANY note

Quick-open (⌘O)

⌘O is the search surface across your whole vault. Fuzzy-match, arrow, and Return opens it in the current top window; ⌘Return pops it into a new sticky. This is discovery — distinct from the ⌘K action menu on the next screen.

04Acts on THIS note

Action menu (⌘K)

⌘K is a command list for the currently focused note — not a search box. Every action shows its own hotkey. Choosing Configure… opens the metadata overlay (next screen); Delete asks to confirm first.

05Configure, in place

Metadata config overlay

Opened from ⌘K → Configure…, the metadata editor appears as a modal inside the note, blurring the content behind it. Edit icon, title, description, group (type-ahead) and tags; created/updated dates, sync status and file location sit in a read-only panel below.

Decisions for the founder to confirm

Accent
Lightning gold — #F0B90B / #FFD21A
Approved. Text-on-light uses a deeper #8A6600 for legibility. Swappable in Settings.
⌘⇧.
Shows / hides all notes
Global toggle for the whole floating layer, focus on the last note used. ⌘N is the blank-note path.
Two palettes
⌘O opens · ⌘K acts
⌘O searches ALL notes; ⌘K is the action menu for THIS note. Kept visually distinct to avoid collision.
Metadata
Modal overlay inside the note
Blurs content behind it. Group is a type-ahead (match or create-on-blur). Dates / sync / path are read-only, hidden from the note.
Focus cue
Quiet gold edge only
No on-top pill, no traffic-lights, no footer date. Footer is a subtle word count. Confirm this is calm enough.
Many notes
Many windows — ships M3
Multi-note = multiple stickies, most-recent on top, ⌘1–9 to switch. Single note ships first.
